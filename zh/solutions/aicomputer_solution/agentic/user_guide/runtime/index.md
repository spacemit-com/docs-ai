# Runtime 管理与监控

<a id="top"></a>

Runtime（运行时）是 BiBit 背后负责执行任务的部分：它理解你的请求，选择合适的模型、工具或技能，按安全策略执行或拦下操作，并记录运行状态。Runtime 管理与监控页面用于查看和调整这些能力，适合需要管理专家、模型服务、能力或安全策略的使用者；只使用聊天或文件功能时，可以不进入这些页面。

## 打开 Runtime 页面

1. 打开 **设置**，在侧栏找到 **管理** 或 **监控** 分组。
2. 点击需要的页面。每个页面直接在右侧显示，不会离开 BiBit 的设置界面。
3. 查看页面顶部的连接状态。出现 **Runtime 已连接** 后，再执行读取或修改操作。

![BiBit 设置中的 Runtime 管理与监控入口](../../images/runtime-overview.png)

**如果没有“管理”或“监控”分组：** 当前设备可能没有安装或启用 Runtime 管理扩展。先到 **设置 → 扩展** 查看状态，安装或启用后按提示重启 BiBit。这些页面管理的是 Runtime 的高级设置；Agent Hub 的 **能力中心** 和普通扩展安装仍在各自的入口完成。

| 管理 | [技能](skills.md) | 查看 Agent 可使用的技能及其说明 |

## 使用前需要知道

- **页面能打开，不代表所有服务都已就绪。** 顶部显示 Runtime 或 securityd 的连接状态；出现不可用提示时，先按提示刷新或检查对应服务，不要连续重复提交修改。
- **修改可能影响正在执行的 Agent。** 专家配置、工具策略、文件权限、网络策略和系统调用策略会在新的运行中生效；已运行的任务不一定立即改变。
- **操作超时不等于没有执行。** MCP、插件和目录变更可能需要较长时间；出现超时或“结果待确认”时，先刷新页面读取实际状态，再决定是否重试。
- **安全页面面向需要调整策略的使用者。** 不确定某项设置的作用时，先保持默认值，或到开发者社区确认后再修改。
